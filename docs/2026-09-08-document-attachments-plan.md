# 随包文档：无需访问本地的项目资料包

## 目标

线上 Chat 负责分析；本地只负责收集、脱敏和打包。README、AGENTS 等文档不能只留下本地引用，选定的正文应随 `ai_context.md` 一起交付。

## 本轮实现

1. 增加每项目 `attach_files`，显式选择已有 `allow_files` 中允许导出的元数据文档。默认关闭，重新发现项目时保留选择；只允许详细可见项目开启。
2. 正文进入候选 manifest 和事实哈希，沿用原有快照审核流程。保留相对路径、行号和脱敏标记。单文件上限 64 KiB，每项目最多 8 份、合计 256 KiB；缺文件或超限报错，不悄悄截断。
3. 附文项目卡包含正文；开启附文时，主文件同时带全部项目卡，避免只有索引、线上读不到分片。问题切片明确说明自身不含完整附件。
4. 附文中的 AGENTS 指令是历史项目资料，不是当前对话指令。敏感行整行替换；私钥块整体替换。安全过滤后仍须审阅候选，不能保证识别所有业务秘密。
5. 验证默认行为不变、敏感内容拦截、权限与路径边界、正文变更可追踪，以及删除本地输入后仍可从候选重建完整资料包。

## 后续与验收边界

不增加本地 AI，不自动上传，不改变真实项目的发布配置，不删除 SOL。先用这两个项目的 README 和 AGENTS 生成私有样例；旧技术报告保留，另补小白结果说明。SOL 替代仍需相同输入、相同问题、相同线上模型的两轮真实比较。本轮工程验证不等于实际线上回答质量验收。

## 本轮结果

已实现并生成本地 0.2.2 安装包。409 项测试通过，其中 26 项覆盖文档附带与相关边界；两套既有合成评测通过，安装后的包也成功重建实际样例。

实际样例包含 SOL 和 Linker 的 README、AGENTS 共 4 份，681 行原文位置保留，33 行敏感内容用标记替换，其他行逐行一致。除新增附件外，同一时刻采集的项目事实不变。主文件从 1,957 字节变成 60,134 字节，目录在同一文件内跳转；测试验证源文件删除后仍能从候选重建资料包。

实际样例、交付回执和源文件核验记录保留在仓库外的私有验证目录。本轮完成时尚未做线上同模型问答比较，不宣称已经替代 SOL；后续观察见 [匿名测试记录](question-test-observations.md)。
